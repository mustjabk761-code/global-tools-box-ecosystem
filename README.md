# Global Tools Box Ecosystem Hub

Welcome to the official open-source repository for the **Global Tools Box Ecosystem**. This hub provides access to high-performance, browser-based web applications, financial calculators, 3D floor visualizers, product launch directories, and professional career tools.

---

## 🚀 Featured Web Applications

### 1. [Global Tools Box](https://globaltoolsbox.online/)
**Global Tools Box** is an all-in-one suite of free web utilities, financial calculators, unit converters, and client-side developer applications built for maximum efficiency and privacy.
* **Website:** [https://globaltoolsbox.online/](https://globaltoolsbox.online/)
* **Key Features:** Fast calculations, no downloads required, privacy-focused client-side execution.

### 2. [PlanScaper](https://planscaper.globaltoolsbox.online/)
**PlanScaper** is an interactive 2D to 3D floor plan visualizer and architectural scene renderer designed for designers, homeowners, and real estate professionals.
* **Website:** [https://planscaper.globaltoolsbox.online/](https://planscaper.globaltoolsbox.online/)
* **Key Features:** WebGL 3D rendering, custom floor plan uploads, browser-based spatial design.

### 3. [ProductNest](https://productnest.online/)
**ProductNest** is a modern product discovery directory for launching, showcasing, and finding new SaaS products, mobile applications, and web tools.
* **Website:** [https://productnest.online/](https://productnest.online/)
* **Key Features:** Free product submissions, maker directory, developer tools showcase.

### 4. [Resume Builder](https://resume.globaltoolsbox.online/)
**Resume Builder** helps job seekers create professional, ATS-friendly resumes effortlessly using optimized layouts and fast browser rendering.
* **Website:** [https://resume.globaltoolsbox.online/](https://resume.globaltoolsbox.online/)
* **Key Features:** ATS compatibility, custom resume design, quick PDF export.

* **Backend & API Proxy:** Cloudflare Workers, Cloudflare R2, Firebase Realtime Database
* **Hosting:** Cloudflare Pages, GitHub Pages
